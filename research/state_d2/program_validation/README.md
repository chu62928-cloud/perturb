# D2 谱系评分器验证

本目录用于保存冻结的 Naive、Th1、Th2、Th17 身份程序在外部参考数据上的验证结果。评分器定义见 [`config/th_lineage_programs.v1.json`](../../../config/th_lineage_programs.v1.json)。

验证顺序固定为：

1. 在 GSE135390 和 Cano-Gamez 等人的人初始 CD4 极化数据中，按供者分别计算每个程序的细胞级分数和受试者工作特征曲线下面积；
2. 要求至少三位供者中的两位方向一致，四个身份程序的宏平均曲线下面积不低于 0.80；
3. 再把相同程序用于 D2 的单基因扰动响应，报告程序方向和效应基因，但不把 Rest、Stim8hr、Stim48hr 当作 Naive、Th1、Th2 或 Th17 标签；
4. FOS/JUN 等泛激活、应激、凋亡、细胞周期和干扰素程序始终独立报告，不混入身份分数。

外部数据验证结果尚未写入本目录前，不得把评分器称为已通过验证。D2 结果也只说明沿冻结程序的移动方向，不能宣称真实谱系转换。
